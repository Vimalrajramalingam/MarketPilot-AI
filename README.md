# MarketPilot AI

MarketPilot AI is a full-stack, AI-powered hyper-local grocery and retail discovery platform. It connects local shoppers with nearby vendors, offering real-time inventory tracking, AI assistant shopping recommendations, QR pickup passes, and vendor management tools.

## Key Features

- **Hyper-Local Store Discovery**: Search and locate local stores and vendors using interactive maps and GPS location.
- **AI Shopping Assistant**: Interactive chatbot for smart product search, budget optimization, and personalized shopping lists.
- **Vendor & Admin Dashboards**: Inventory management, sales analytics, and AI business tools for store owners.
- **Cart & QR Pickup Passes**: Seamless online checkout with self-pickup options and generated QR codes for store verification.
- **Responsive UI**: Built with React, Tailwind CSS, and Lucide Icons.

## Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Motion (Framer Motion)
- **Backend / API**: Express, Node.js
- **Routing**: React Router DOM
- **Deployment**: Compatible with Vercel, Netlify, and Cloud Run

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The application will run on `http://localhost:3000`.

### Build for Production

```bash
npm run build
npm start
```
